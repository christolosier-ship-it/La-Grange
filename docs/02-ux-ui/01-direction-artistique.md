# Direction artistique

## Intention

La Grange est un atelier numérique chaleureux, nocturne et accueillant. Le décor s’appuie sur le bois sombre, le papier, le métal patiné et une lumière ambrée. L’ensemble doit évoquer un lieu réel sans reproduire littéralement une ferme.

## Ratio de conception

- 70 % interface moderne, nette et fonctionnelle ;
- 30 % matière, narration et ambiance.

## Référence visuelle

Le prototype validé montre :

- une navigation verticale à gauche ;
- une poutre de statistiques en partie haute ;
- des cartes projets illustrées ;
- une colonne d’activité à droite ;
- des panneaux en bois et papier ;
- un éclairage chaud et localisé.

Le prototype est une cible d’ambiance, pas une spécification pixel-perfect. Les données non fiables du visuel, notamment les progressions inventées, doivent être remplacées.

## Matières

- bois : structure, séparateurs, arrière-plan ;
- métal : bordures, badges, boutons secondaires ;
- papier : messages, notes, états vides ;
- verre sombre : surfaces de données secondaires.

## Garde-fous

- jamais de texture derrière un long texte sans fond uni ;
- pas d’ombre excessive ;
- pas de police décorative pour le corps ;
- pas d’animation permanente ;
- pas de brun sur brun insuffisamment contrasté ;
- les identités des projets peuvent être plus colorées que le shell.
