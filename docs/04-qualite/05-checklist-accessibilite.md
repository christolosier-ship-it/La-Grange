# Checklist accessibilité

## Structure

- [ ] langue du document définie ;
- [ ] landmarks présents ;
- [ ] titres hiérarchisés ;
- [ ] lien d’évitement ;
- [ ] titre de page mis à jour.

## Clavier

- [ ] ordre de tabulation logique ;
- [ ] focus toujours visible ;
- [ ] aucune zone inaccessible ;
- [ ] Escape ferme les overlays ;
- [ ] focus restauré après fermeture ;
- [ ] pas de piège clavier hors modal.

## Contenu

- [ ] labels explicites ;
- [ ] images avec alt adapté ;
- [ ] liens externes identifiables ;
- [ ] dates complètes accessibles ;
- [ ] erreurs associées au contexte ;
- [ ] statut non transmis uniquement par couleur.

## Visuel

- [ ] contrastes AA ;
- [ ] zoom 200 % ;
- [ ] texte agrandi sans chevauchement ;
- [ ] zones tactiles suffisantes ;
- [ ] orientation portrait et paysage ;
- [ ] textures derrière surfaces lisibles.

## Mouvement

- [ ] `prefers-reduced-motion` respecté ;
- [ ] aucune animation clignotante ;
- [ ] aucune information dépendant d’un mouvement.

## Validation

- [ ] audit automatisé ;
- [ ] navigation clavier manuelle ;
- [ ] VoiceOver iOS ;
- [ ] contrôle sur tablette réelle.
