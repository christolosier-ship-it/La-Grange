# Checklist accessibilité

## Structure

- [ ] langue définie ;
- [ ] landmarks ;
- [ ] `h1` accessible ;
- [ ] lien d’évitement ;
- [ ] rail identifié ;
- [ ] contenu principal unique ;
- [ ] décor sans régions inutiles.

## Rail et scroll

- [ ] rail fixe sans recouvrir le contenu ;
- [ ] navigation atteignable ;
- [ ] synchronisation annoncée ;
- [ ] version lisible ;
- [ ] état admin textuel ;
- [ ] scroll principal clavier et tactile ;
- [ ] zoom 200 %.

## Carte

- [ ] nom visible ;
- [ ] couverture avec alt concis ;
- [ ] logo décoratif si nom déjà présent ;
- [ ] date complète accessible ;
- [ ] progression annoncée « estimation manuelle » ;
- [ ] cinq cibles de 44 px ;
- [ ] ordre GitHub, app, README, détail, personnalisation ;
- [ ] lien absent sans bouton mort ;
- [ ] bouton admin absent hors session.

## Infobulles

- [ ] survol ;
- [ ] focus ;
- [ ] Échap ;
- [ ] pas d’information exclusive ;
- [ ] `aria-label` ou nom visible ;
- [ ] pas de recouvrement bloquant.

## Modale

- [ ] rôle et titre ;
- [ ] description ;
- [ ] focus initial ;
- [ ] piège Tab ;
- [ ] fond inerte ;
- [ ] Échap avant opération non annulable ;
- [ ] erreurs de champs ;
- [ ] erreur serveur ;
- [ ] état occupé ;
- [ ] focus restauré.

## Visuel

- [ ] contrastes AA ;
- [ ] texture contrôlée ;
- [ ] palettes personnalisées validées ;
- [ ] focus au-dessus des WebP ;
- [ ] cibles tactiles ;
- [ ] mouvement réduit ;
- [ ] images bloquées ;
- [ ] couleurs forcées.

## Validation

- [ ] audit automatisé ;
- [ ] clavier manuel ;
- [ ] VoiceOver iPad ;
- [ ] tablette paysage ;
- [ ] bureau ;
- [ ] écran bas ;
- [ ] zoom 200 % ;
- [ ] administrateur connecté et déconnecté.
