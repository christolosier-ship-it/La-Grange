# Contexte utilisateur

## Utilisateur principal

La Grange est conçue d’abord pour un utilisateur unique possédant de nombreux dépôts publics : applications PWA, jeux, prototypes, outils professionnels et projets d’apprentissage.

## Problème actuel

Le profil GitHub expose les dépôts sous une forme technique et uniforme. Il ne montre pas clairement :

- l’identité de chaque application ;
- son usage réel ;
- l’existence d’un déploiement ;
- son niveau d’activité ;
- les liens utiles ;
- la cohérence globale de l’écosystème.

## Contexte d’usage

- consultation sur iPad avant une session de développement ;
- ouverture rapide d’une application sur smartphone ;
- présentation de l’écosystème sur ordinateur ;
- consultation intermittente avec réseau faible ;
- découverte d’un nouveau dépôt automatiquement.

## Hypothèse centrale

La valeur vient moins de la quantité de données que de leur présentation cohérente et du raccourcissement du chemin vers chaque projet.
