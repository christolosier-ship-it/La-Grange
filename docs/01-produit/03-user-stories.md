# User stories

## Consultation

- Je veux voir le cache immédiatement.
- Je veux que les nouveaux dépôts apparaissent automatiquement.
- Je veux connaître le temps écoulé depuis la dernière activité.
- Je veux ouvrir GitHub, l’application, le README et le détail depuis la carte.
- Je veux qu’un lien absent ou une image absente ne crée pas de bouton mort.

## Dashboard

- Je veux que le menu reste fixe pendant le défilement des projets.
- Je veux lire les statistiques sur un seul bandeau.
- Je veux parcourir une grille continue sans conteneurs ni titres redondants.
- Je veux conserver cinq actions alignées sur tablette paysage et bureau.

## Administration

- Je veux me connecter comme administrateur sans exposer de token.
- Je veux personnaliser un projet dans une modale.
- Je veux prévisualiser le résultat avant publication.
- Je veux qu’une PR soit créée automatiquement.
- Je veux voir le lien et l’état de la PR.
- Je veux retrouver la personnalisation sur mes autres appareils après fusion et déploiement.
- Je ne veux pas que la personnalisation modifie le dépôt du projet concerné.
