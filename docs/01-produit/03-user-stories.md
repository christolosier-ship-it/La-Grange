# User stories

## Synchronisation

- En tant qu’utilisateur, je veux que mes nouveaux dépôts apparaissent automatiquement afin de ne pas maintenir une liste manuelle.
- Je veux voir le dernier cache immédiatement afin de ne pas attendre le réseau.
- Je veux connaître la date de dernière synchronisation afin de juger la fraîcheur des données.
- Je veux conserver l’ancien instantané si GitHub échoue afin de ne pas vider La Grange.

## Consultation

- Je veux reconnaître un projet par sa couverture.
- Je veux rechercher par nom, description, topic ou langage.
- Je veux filtrer les projets publiés, actifs, en sommeil ou archivés.
- Je veux ouvrir une fiche sans perdre le contexte de navigation.

## Accès

- Je veux ouvrir directement l’application lorsqu’elle existe.
- Je veux accéder au dépôt, au README, aux releases et aux issues.
- Je veux qu’un lien absent ne produise pas un bouton mort.

## Confort

- Je veux utiliser La Grange sur tablette, mobile et bureau.
- Je veux pouvoir réduire les animations.
- Je veux distinguer clairement le mode hors ligne d’une synchronisation réussie.
