# Phase 6 — Polissage visuel

## Objectif

Atteindre l’identité du prototype sans dégrader le MVP fonctionnel.

## Travaux

1. finaliser logo et enseigne ;
2. produire textures optimisées ;
3. préparer couvertures et logos des projets prioritaires ;
4. finaliser cadres, badges et panneaux ;
5. ajuster lumière et profondeur ;
6. intégrer animations autorisées ;
7. créer l’arrivée d’une nouvelle caisse ;
8. contrôler les contrastes ;
9. optimiser chaque asset ;
10. tester avec et sans overrides ;
11. vérifier mouvement réduit ;
12. réaliser revue visuelle multi-écrans.

## Règles d’assets

- dimensions documentées ;
- WebP ou AVIF pour les couvertures ;
- PNG uniquement si transparence nécessaire ;
- SVG local pour icônes ;
- poids budgété ;
- noms de fichiers stables ;
- fallback toujours fonctionnel.

## Critères de sortie

- reconnaissance immédiate de La Grange ;
- lisibilité supérieure au prototype conceptuel ;
- aucun texte sur texture incontrôlée ;
- temps de chargement acceptable ;
- aucune animation obligatoire ;
- cohérence entre mobile, tablette et bureau.
