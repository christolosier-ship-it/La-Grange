# Phase 4 — Catalogue et fiche projet

## Objectif

Permettre de retrouver et d’explorer chaque projet.

## Catalogue

1. recherche multi-champs ;
2. filtres d’état, catégorie, langage et favoris ;
3. tris ;
4. modes grille et liste ;
5. synchronisation des filtres utiles avec l’URL ;
6. état vide et reset ;
7. conservation du contexte au retour.

## Fiche

1. hero, logo et couverture ;
2. description ;
3. actions principales ;
4. métadonnées ;
5. topics ;
6. détails à la demande ;
7. cache des détails ;
8. route inconnue et projet renommé ;
9. navigation externe sécurisée.

## Critères de sortie

- recherche instantanée sur tous les projets ;
- filtres combinables ;
- URL directe de fiche ;
- aucun bouton mort ;
- détails en erreur sans casser la fiche ;
- retours corrects ;
- accessibilité clavier et VoiceOver ;
- charge API maîtrisée.
