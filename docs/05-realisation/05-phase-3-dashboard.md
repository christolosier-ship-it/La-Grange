# Phase 3 — Dashboard

## Objectif

Transformer les données réelles en page d’accueil claire et déjà fidèle au prototype.

## Travaux

1. créer statistiques calculées ;
2. créer ProjectCard et ses variantes ;
3. créer L’établi ;
4. créer Prêts à partir ;
5. créer panneau d’activité ;
6. créer répartition des états sans bibliothèque lourde ;
7. afficher nouvelle arrivée ;
8. intégrer navigation latérale et mobile ;
9. gérer fallback d’image ;
10. charger les couvertures paresseusement ;
11. couvrir tous les états réseau ;
12. finaliser responsive principal.

## Statistiques autorisées

- total de projets ;
- projets actifs ;
- applications lançables ;
- archives.

## Critères de sortie

- aucune donnée fictive ;
- dashboard exploitable sur iPad ;
- carte entièrement accessible ;
- première information visible depuis le cache ;
- aucun layout shift important ;
- nouveau repo repérable ;
- sections vides traitées proprement ;
- tests de composants et captures de contrôle.
