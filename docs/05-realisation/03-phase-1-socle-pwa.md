# Phase 1 — Socle PWA

## Objectif

Obtenir une application vide mais solide, installable et navigable.

## Travaux

1. initialiser Vite et TypeScript strict ;
2. configurer le `base` GitHub Pages ;
3. créer `index.html`, bootstrap et app shell ;
4. implémenter le routeur hash ;
5. créer le store minimal ;
6. installer les tokens CSS, reset et typographie ;
7. créer les layouts responsive ;
8. ajouter manifest et icônes provisoires ;
9. ajouter service worker ou plugin PWA justifié ;
10. créer les vues placeholders ;
11. ajouter tests du routeur et build CI.

## Non inclus

Aucun appel GitHub, aucune vraie carte projet et aucun asset final.

## Critères de sortie

- toutes les routes s’ouvrent ;
- navigation clavier de base ;
- build production ;
- déploiement de prévisualisation Pages possible ;
- shell disponible hors ligne ;
- aucun warning TypeScript ;
- tests routeur verts ;
- Lighthouse PWA sans erreur structurante.

## Revue particulière

Vérifier le chemin des assets sous `/La-Grange/`, la navigation après rechargement et l’absence d’une dépendance disproportionnée.
