# Phase 0 — Documentation et fondations

## Objectif

Créer la charpente de référence avant toute implémentation.

## Livrables

- vision, périmètre et glossaire ;
- user stories et règles métier ;
- vues, composants et design system ;
- architecture technique ;
- modèle de données ;
- stratégie GitHub, synchronisation et cache ;
- stratégie PWA, sécurité et performance ;
- tests, définition de terminé et audit ;
- ADR ;
- prompts de génération ;
- README, AGENTS et contribution.

## Travaux

1. relire la cohérence transversale ;
2. supprimer les contradictions ;
3. vérifier que chaque fonction du MVP possède critères et tests ;
4. vérifier que le hors périmètre est explicite ;
5. figer les noms des routes et concepts ;
6. ouvrir une PR documentaire ;
7. auditer le diff ;
8. fusionner après validation.

## Critères de sortie

- index complet ;
- aucun document vide ;
- ADR cohérents ;
- architecture réalisable sans secret ;
- plan de phases exploitable par un agent ;
- documentation fusionnée sur `main`.
