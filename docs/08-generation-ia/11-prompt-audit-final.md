# Prompt d’audit final

Audite La Grange avant release en utilisant `docs/04-qualite/08-checklist-audit-final.md` et la matrice de traçabilité.

## Méthode

Analyser tout le code, comparer l’architecture réelle aux ADR, exécuter les commandes qualité, inspecter le build, tester API simulée, cache, hors ligne, responsive, sécurité des liens, service worker et migrations.

## Rapport

- synthèse Go / No-Go ;
- anomalies classées ;
- preuves de tests ;
- exigences non couvertes ;
- écarts documentaires ;
- performances ;
- accessibilité ;
- sécurité ;
- PWA ;
- corrections obligatoires ;
- risques résiduels.

Ne jamais conclure positivement sans preuve. Toute limite d’outil ou test non réalisable est déclarée.
