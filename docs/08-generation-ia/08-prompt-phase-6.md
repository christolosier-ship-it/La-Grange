- section « L’établi » ;
- section « Prêts à partir » ;
- lien « Voir tout l’inventaire » ;
- rail droit ;

- texte rasterisé ;
- secret client ;
- écriture hors `La-Grange` ;
- commit direct sur `main` ;

- bureau ;

- hors ligne ;
