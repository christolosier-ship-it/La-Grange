# Prompt Phase 3 — Dashboard

Implémente exclusivement `docs/05-realisation/05-phase-3-dashboard.md` et les spécifications UX associées.

## Cible

Créer le dashboard chaleureux validé : navigation atelier, quatre statistiques réelles, L’établi, Prêts à partir, activité, répartition et nouvelle arrivée.

## Règles

- utiliser uniquement les données du store ;
- pas de pourcentage d’avancement ;
- fallback visuel pour chaque projet ;
- couverture lazy-loaded ;
- carte accessible et non imbriquée incorrectement ;
- fonctionnement sur cache ;
- messages hors ligne et limite API ;
- mobile, tablette et bureau ;
- mouvement réduit.

## Contrôles

Comparer visuellement au prototype sans copier ses données fictives. Tester sections vides, image en erreur, description longue, nom long, projet archivé et nouveau repo.

## Rapport

Fournir captures ou description de contrôle par format, poids des assets, tests exécutés et différences volontaires avec le prototype.
