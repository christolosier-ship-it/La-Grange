# Vision produit

La Grange donne une existence visible et cohérente à l’ensemble des projets GitHub de Christo. Elle remplace la liste technique des dépôts par un atelier numérique où chaque application possède une identité, un état synthétique et des portes d’accès claires.

## Proposition de valeur

> Ouvrir un seul lieu pour retrouver, comprendre et lancer n’importe quel projet.

## Résultat attendu

À l’ouverture, l’utilisateur voit immédiatement :

- combien de projets existent ;
- lesquels ont récemment bougé ;
- lesquels sont directement utilisables ;
- quels nouveaux dépôts sont apparus ;
- comment ouvrir chaque application ou son dépôt.

## Expérience recherchée

La Grange doit donner envie d’être ouverte quotidiennement, sans exiger d’action. Elle observe et présente. Son ambiance évoque un atelier sombre, chaleureux et vivant, mais la hiérarchie reste celle d’une interface moderne.

## Anti-vision

La Grange ne doit pas devenir :

- une surcouche de gestion GitHub ;
- un réseau social ;
- un gestionnaire de tâches ;
- une collection de métriques vaniteuses ;
- une interface décorative où le bois rend les informations illisibles.
