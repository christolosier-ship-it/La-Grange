# Vision produit

La Grange donne une existence visible et cohérente aux projets GitHub de Christo. Elle remplace la liste technique des dépôts par un atelier numérique où chaque projet possède une identité, un état synthétique et des accès directs.

## Proposition de valeur

> Ouvrir un seul lieu pour retrouver, comprendre, lancer et personnaliser n’importe quel projet.

## Résultat attendu

À l’ouverture, l’utilisateur voit immédiatement :

- le nombre réel de projets ;
- les projets actifs et archivés ;
- les applications directement lançables ;
- la dernière activité constatée ;
- l’identité visuelle, la version et l’avancement éditorial facultatif de chaque projet ;
- les accès vers GitHub, l’application, le README et le détail.

## Administration limitée

La Grange conserve une consultation publique. Une session administrateur permet seulement de personnaliser les données éditoriales de La Grange. Toute modification est proposée dans une pull request du dépôt `La-Grange`, jamais appliquée directement aux dépôts présentés.

## Anti-vision

La Grange ne devient pas :

- un gestionnaire d’issues ou de pull requests ;
- un Kanban ou un outil de planification ;
- un tableau de métriques vaniteuses ;
- une interface mobile généraliste ;
- un décor composé de conteneurs imbriqués ;
- une application contenant un secret GitHub côté client.
